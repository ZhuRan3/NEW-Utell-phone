## 1. 问题定义

为第一代智能日志 MVP 选择首发手机平台和 UI 技术栈，使一名 Owner 能可靠交付 PRD 中的 P0 范围：扫码配对与公钥指纹确认、链路状态机（UNPAIRED/CONNECTING/NOT_READY_*/UNKNOWN/READY）、READY 门禁下的文字提交、E2EE 客户端、Card Projection 渲染与版本去重、在线确认/纠正（携带 expectedVersion）、脱敏诊断导出。

本决定包含两个子问题：**(a) 首发平台范围**（仅 iOS / iOS+Android 同期）——这是产品决定，直接改变技术栈推荐；**(b) 对应技术栈**。

- 范围：首发手机平台、最低系统版本、UI 框架、状态管理、安全存储、WSS 与加密库集成方式。
- 非范围：PC Connector、Relay、Pi 内部技术；提醒、语音、多模态等非 P0 能力。
- 最晚决定时间：开始 Mobile Shell 生产骨架前。

## 2. 硬约束（来自 PRD）

- 私钥必须进入平台安全存储，不进入日志、二维码、诊断导出或备份。
- 业务原文、提交任务、Card Projection 只允许当前会话内存存在；App 退出/崩溃后不可恢复。
- 支持 WSS 长连接、断线重连、应用层 E2EE（成熟密码库）与固定测试向量。
- 支持扫码、指纹展示确认和前台状态可视化；关键状态必须有文本形式（可访问性）。
- 页面与状态具有稳定语义，可做单元、契约和真机测试。
- 一名 Owner 可维护首发平台。

## 5. 候选矩阵

| 维度 | A. SwiftUI iOS first | B. Flutter 双端 | C. KMP + 原生 UI |
| --- | --- | --- | --- |
| 首发仅 iOS 时交付速度 | 最快（工具链已就绪） | 中（需装工具链+迁移期风险） | 最慢（三语言两层 UI） |
| iOS+Android 同期 | 不满足 | 核心优势 | 可行但 UI 仍两套 |
| 安全存储/扫码/生命周期 | 官方 API 直接接入 | 依赖第三方插件（质量参差是结构性弱点） | 分端各自接入 |
| E2EE 密码库 | CryptoKit/swift-crypto 官方维护 | cryptography 无公开审计 | 官方库消失，依赖单作者库 |
| 生态当前风险 | 年更稳定，无弃用信号 | 三迁移叠加（拆包/SPM/UIScene） | Swift Export Alpha，互操作不稳定 |
| 单 Owner 长期维护 | 单语言单平台 | 单语言双平台 + 插件供应链面 | 三语言 + 双 UI，负担最重 |
| 最强失败场景 | MVP 后要 Android 时 UI 全重写 | 迁移期插件兼容性踩坑 | 集成成本吞噬 P0 时间 |
| 退出路线 | 保持契约后新增 Android 端 | 保持契约后重写原生端 | 退回任一原生端或 Flutter |

不使用单一总分；子问题 (a) 首发平台范围的答案直接决定推荐。

## 6. 失败、迁移和退出路线

跨端契约（Relay Transport / Connector Service）与平台无关，任何候选退出都不改变协议与数据语义。A 的退出成本集中在 UI/状态层重写为 Android 原生或 Flutter；B/C 的退出成本是共享层废弃。E2EE 库选择需与 Connector 侧（Painfox）共同接受测试向量，属于 integration-profile 门禁。

## 7. AI 建议

- 若子问题 (a) 答案为"首发仅 iOS"：推荐候选 A（SwiftUI），置信度中高。理由：P0 全部硬约束（Keychain、CryptoKit、WSS、扫码、可访问性）均为官方一等能力，零第三方供应链面；本机工具链已就绪；Flutter 恰逢三迁移叠加期，KMP 的 Swift 互操作仍 Alpha。
- 若子问题 (a) 答案为"iOS+Android 同期"：推荐候选 B（Flutter），置信度中。须接受迁移期风险并把关键插件兼容性 Spike 前置；C 在单 Owner 约束下不推荐。
- 最强反对理由（对 A）：若产品 6-12 个月内必须上 Android，A 的 UI 重写成本最高，B 的共享代码价值会反超。
- 剩余风险：E2EE 具体协议/库（Noise 或其他）需与 Connector 侧共同冻结；iOS 后台 WSS 限制需真机验证重连体验。
- 仍需证据：见下方 Spike 清单。

### 需 Spike（E3）验证的空白

1. WSS 断连/后台恢复/网络切换的真机行为与"恢复连接"体验（最高优先）。
2. Keychain 真机边界（卸载/重装、Simulator 差异）。
3. E2EE 候选库与 Connector 侧的固定测试向量互操作。
4. 若走 Flutter：flutter_secure_storage、扫码插件在 3.47 迁移期的兼容性空工程实测。
5. 列表页可访问性文本 + 稳定语义 ID 的 UI 测试可用性。
